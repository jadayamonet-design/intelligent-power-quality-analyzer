Intelligent Power Quality Analyzer
An STM32-based embedded power monitoring system designed to acquire voltage and current waveforms and perform real-time power and power-quality analysis.
Planned Capabilities
• RMS voltage and current measurement
• Real, reactive, and apparent power calculation
• Power factor measurement
• Frequency estimation
• FFT-based harmonic analysis
• Total harmonic distortion (THD) calculation
• Voltage sag and swell detection
• Real-time Python visualization
• STM32 embedded data acquisition
• Custom PCB implementation
Technology
STM32F446RE • Embedded C • Python • NumPy • SciPy • Matplotlib • KiCad • LTspice • Git/GitHub
